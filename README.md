# KANMA Elegance Design

Responsive, accessible static fashion landing page for KANMA Elegance Design, Gwagwalada, Abuja.

## Run locally

Serve `dist` with any static web server, for example `npx serve dist`.

## Deploy

Import this repository in Vercel. Framework: Other. Output directory: `dist`. No build command or dependencies required. Or run `vercel --prod` from this directory.

## Search visibility

The page includes a descriptive title, local search copy, meta description, semantic markup, accessible image text and LocalBusiness structured data. Set canonical URL, og:url, robots.txt and sitemap.xml to the final production origin. Submit the sitemap in Google Search Console after verifying ownership. Google controls indexing and ranking.

A Google Business Profile is separate from the website. Its setup requires confirming the business type, accurate address or service area, category, hours and ownership verification. Never invent a map pin or publish a private address without confirming its business use.
